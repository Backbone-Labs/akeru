# Whatajong local opening-board port

Run `node packages/whatajong/build.mjs`, then `node packages/whatajong/preview.mjs` using the root's pinned Node/npm versions. This explicit build fetches only into ignored `dist/external`, reads the pinned inventory revision, checks every selected Git blob, and produces an integrity-recorded local title in ignored `dist/whatajong`. `whatajongOptions()` from `packages/whatajong/catalog.mjs` joins other local catalog options. No source, upstream assets, dependencies or generated title outputs are checked in.

This is an actual upstream engine port: game.ts, Database, the responsive map, setupTiles and shuffle execute from the pinned source. The initial 27-pair deck is provided by upstream getInitialPairs. The preview preserves tile freedom/overlap, matching, scoring, blocked-board detection and the solvable deal algorithm. All special tile resolver modules are included as original code, but the opening deck does not expose special tiles. The original campaign, rewards, shop, timers and desktop application are outside this opening-board preview. A new board is another opening-board deal, not campaign progression.

Node's pinned built-in TypeScript transform erases types. An explicit import allowlist routes Solid stores to a small synchronous adapter because the Akeru view redraws after actions; Database's indexes and lookup rules stay upstream. Framework animation, audio and telemetry hooks become no-ops. A local Math.random provider replaces rand-seed, so identical upstream seeds are not reproduced; the original shuffle and solvable placement algorithm are unchanged. No unreviewed npm dependencies are installed. New CSS tile faces and system lettering visibly replace all original artwork, fonts and audio. These replacement faces are a visual adaptation, not a claim of visual fidelity.

Guest saves use only the existing host-owned save client, never title storage. Restore checks the exact opening deck, layout, selected/free tile, removed pairs and score; unreadable or invalid saves block all writes for that session. Keyboard, pointer, touch and host controller events pass through the authenticated runtime bridge; host pause blocks input. Arrow navigation visits only free tiles, and A/Enter selects. R starts another board; B or the touch Hint control highlights an available pair. After a cleared or blocked board, A starts a fresh deal.

Source root license is MIT, with its copyright notice retained in generated output. Source/asset rights are still unknown and publication approval remains pending. Upstream art, fonts, sound, Electron, original storage and analytics are excluded. This build does not publish or activate anything.

After explicitly building, run `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npx playwright test tests/browser/whatajong-preview.spec.mjs`. The browser test writes an ignored `dist/previews/whatajong.png` cover.
